Research

Program analysis

  • Earlier: Improved analysis of unsafe data flows in dynamic PHP and JavaScript, uncovering 54 previously unknown vulnerabilities in 19 PHP applications (CoBrA) and 242 in npm packages (FAST).
  • Now: Beyond unsafe data flows, logic vulnerabilities depend on an application's business rules. I now combine program analysis with agent assistance to check predefined rules; this work has found 47 previously unknown logic vulnerabilities in PHP e-commerce applications.
  • Next: How can we discover logic vulnerabilities when the relevant business rules are not given? I want to identify candidate rules and test whether violating them has security consequences.

CoBrA · ICSE 2026FAST · IEEE S&P 2023AnonVul · Preprint 2026

Agentic security

  • Related work: Showed that prior dialogue changes assistance on identical cybersecurity requests.
  • Exploring: Does this context sensitivity carry into agents' actions? I want to study how task and authorization constraints hold across tool use, and where logic vulnerabilities arise.

CoBrA: Context-, Branch-sensitive Static Analysis for Detecting Taint-style Vulnerabilities in PHP Web Applications

PaperCodePDF

First author

PHP applications can choose which functions to call at runtime, making vulnerabilities difficult to detect statically. I designed and built CoBrA to resolve these calls using their calling context and track unsafe input flows. It found 54 previously unknown vulnerabilities in 19 web applications.
